# 🤝 Contribution Guidelines

Thank you for considering contributing to this web resources repository.

## What kind of contributions am I looking for?

- New useful resources
- Fixing broken links
- Improving descriptions
- Translations or updates

## How to add a new resource

### In the main README

1. Find the appropriate category
2. Add a new row to the table:
   ```markdown
   | Resource | Category | URL |
   ```
3. Use consistent emojis in categories:
   - 📕 = Book
   - 📘 = Docs (documentation & tutorials)
   - 🧑‍🧒‍🧒 = Blog / community
   - 📝 = Article
   - 🛠️ = Tool
   - 🎥 = Video
   - 🏞️ = Image
   - 📌 = Tips
   - 📚 = Collection
